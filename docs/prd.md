## 1. ภาพรวมโปรเจกต์
เว็บไซต์สำหรับชมรมอาสาพัฒนา มีหน้าที่หลัก 4 อย่าง: แนะนำตัวชมรมให้คนภายนอกรู้จัก, แจ้งเตือนผู้สมัครสมาชิกและสมาชิกปัจจุบันเกี่ยวกับค่ายอาสาต่าง ๆ, เป็นช่องทางให้องค์กร/สปอนเซอร์ติดต่อเพื่อสนับสนุน และมีปฏิทินกิจกรรมให้ผู้เข้าเว็บดูกำหนดการได้สะดวก

## 2. เป้าหมายของเว็บไซต์
- สร้างความน่าเชื่อถือและภาพลักษณ์ที่ดีของชมรมต่อบุคคลภายนอก
- ทำให้สมาชิก (ทั้งใหม่และเก่า) ไม่พลาดข่าวสารเรื่องค่าย ตั้งแต่เปิดรับสมัครจนถึงวันเดินทาง
- เปิดช่องทางที่เป็นทางการสำหรับองค์กรที่สนใจสนับสนุนสปอนเซอร์
- ให้ทุกคนเห็นภาพรวมกำหนดการกิจกรรมทั้งปีผ่านปฏิทินเดียว

## 3. กลุ่มผู้ใช้เป้าหมาย (Target Users)

| กลุ่มผู้ใช้ | สิ่งที่ต้องการจากเว็บไซต์ |
|---|---|
| ผู้สมัครสมาชิกใหม่ | รู้จักชมรม เห็นค่ายที่เปิดรับ สมัครง่าย |
| สมาชิกปัจจุบัน | ดูตารางค่าย รับการแจ้งเตือนไม่พลาดกำหนดการ |
| บุคคลทั่วไป/ผู้ปกครอง | เข้าใจว่าชมรมทำอะไร น่าเชื่อถือแค่ไหน |
| สปอนเซอร์/องค์กร | เห็นผลงาน ติดต่อสนับสนุนได้สะดวก |

## 4. ขอบเขตฟีเจอร์ (Features)

### 4.1 หน้าแนะนำชมรม (Home / About Us)
- หน้าแรกสรุปว่าชมรมคืออะไร ทำอะไร มีวิดีโอ/รูปภาพกิจกรรมเด่น
- หน้า "เกี่ยวกับเรา": พันธกิจ/วิสัยทัศน์ ประวัติชมรม โครงสร้างทีม/คณะกรรมการ
- แกลเลอรีภาพกิจกรรมย้อนหลัง เพื่อสร้างความน่าเชื่อถือ

### 4.2 หน้าค่ายและกิจกรรม
- รายการค่าย แบ่งเป็น "กำลังเปิดรับสมัคร", "กำลังจะมาถึง", "ที่ผ่านมาแล้ว"
- หน้ารายละเอียดค่ายแต่ละค่าย: วันที่ สถานที่ คุณสมบัติผู้สมัคร ปิดรับสมัครวันไหน ปุ่มสมัคร
- ฟอร์มสมัครเข้าค่ายออนไลน์ (แทนกรอกกระดาษ)
- ค่ายประจำปี (3 ค่าย/ปี):
  1. **ค่ายจุดประกาย**
  2. **ค่ายสร้าง**
  3. **ค่ายวันเด็ก**

### 4.3 ระบบแจ้งเตือนสมาชิก
ช่องทาง (เลือกใช้ตามบริบทกลุ่มเป้าหมายเป็นนักเรียน/นักศึกษาไทย):
- **หลัก**: LINE Official Account (LINE OA) ผ่าน LINE Messaging API — คนไทยเปิดอ่านข้อความ LINE สูงกว่าอีเมลมาก เหมาะสำหรับเตือนก่อนปิดรับสมัคร/ก่อนวันเดินทาง
  - หมายเหตุ: LINE Notify ปิดให้บริการไปแล้ว ต้องใช้ LINE Messaging API + LINE OA แทน
- **สำรอง**: อีเมล สำหรับการยืนยันที่เป็นทางการ เช่น ยืนยันการสมัคร, ใบตอบรับ, ติดต่อกับสปอนเซอร์
- **แจ้งเตือนในเว็บไซต์**: แบนเนอร์/ป้ายประกาศหน้าแรกสำหรับข่าวด่วนทั่วไป

### 4.4 ปฏิทินกิจกรรม
- ปฏิทินแบบ interactive แสดงกำหนดการค่าย/กิจกรรมทั้งหมด กดดูรายละเอียดแต่ละวันได้
- รองรับการเพิ่มกิจกรรมลงปฏิทินส่วนตัวของผู้ใช้ (เช่น ปุ่ม "Add to Google Calendar")

### 4.5 หน้าติดต่อสปอนเซอร์
- อธิบายเหตุผลว่าทำไมควรสนับสนุนชมรม พร้อมผลงาน/สถิติที่ผ่านมา
- แสดงโลโก้สปอนเซอร์เดิม (ถ้ามี) เพื่อสร้างความน่าเชื่อถือ — ปัจจุบันยังไม่มีข้อมูลสปอนเซอร์ ใส่ทีหลัง
- ฟอร์ม/ช่องทางติดต่อโดยตรง (อีเมล หรือฟอร์มติดต่อในเว็บ)

### 4.6 ระบบสมัครสมาชิก
- ฟอร์มสมัครสมาชิกออนไลน์ เก็บข้อมูลผู้สมัคร
- ส่งอีเมล/LINE ยืนยันอัตโนมัติเมื่อสมัครสำเร็จ

### 4.7 ระบบหลังบ้าน (Admin Panel)
เจ้าหน้าที่ชมรมสามารถ (ไม่ต้องพึ่งโปรแกรมเมอร์ทุกครั้งที่มีอัปเดต):
- เพิ่ม/แก้ไข/ลบ ค่ายและกิจกรรม
- อัปโหลดรูปภาพ/ข่าวสาร
- ดูรายชื่อผู้สมัครสมาชิก/ผู้สมัครเข้าค่ายแต่ละค่าย
- จัดการข้อความติดต่อจากสปอนเซอร์
- ต้องมีระบบล็อกอินแยกสิทธิ์ (เฉพาะทีมงานเข้าได้)

## 5. ข้อกำหนดทางเทคนิค (Technical Requirements)
ข้อจำกัดสำคัญ: ต้องโฮสต์ฟรีได้ และต้องรองรับ Admin panel (มีฐานข้อมูล ไม่ใช่เว็บสถิตย์ล้วน)

สแตกที่ใช้จริงในโปรเจกต์นี้ (ฟรีในระดับการใช้งานของชมรม, ดู `CLAUDE.md`):
- **Frontend/Framework**: Next.js (App Router) — SEO ดี, responsive ง่าย, deploy ฟรีบน Vercel
- **Hosting**: Vercel (free tier)
- **ฐานข้อมูล + Auth + Storage**: Supabase (free tier) — เก็บข้อมูลค่าย สมาชิก ผู้สมัคร รูปภาพ และใช้ Auth คุมสิทธิ์ Admin
- **การแจ้งเตือน**: LINE Messaging API (ผ่าน LINE OA) เป็นช่องทางหลัก + อีเมล (Resend) เป็นตัวเลือกสำรอง/ยืนยันทางการ
- **ปฏิทิน**: library ปฏิทิน (เช่น FullCalendar) + ปุ่ม sync ไป Google Calendar

## 6. Non-Functional Requirements
- **Mobile-first**: กลุ่มเป้าหมายส่วนใหญ่เข้าเว็บผ่านมือถือ ต้อง responsive เต็มรูปแบบ
- **ภาษา**: ภาษาไทยเป็นหลัก
- **งบประมาณ**: โฮสต์ฟรีได้ตลอด ไม่มีค่าใช้จ่ายรายเดือนในช่วงเริ่มต้น
- **ความเร็ว**: โหลดหน้าเร็ว โดยเฉพาะหน้าแรกและหน้ารายการค่าย
- **ความปลอดภัยข้อมูล**: ข้อมูลผู้สมัคร/สมาชิกต้องเก็บอย่างปลอดภัย จำกัดสิทธิ์เข้าถึงเฉพาะ Admin
- **โทนสี/แบรนด์**: ฟ้า, น้ำเงิน, ขาว — ใช้เป็นชุดสีหลักของ Tailwind theme

## 7. นอกขอบเขต (Out of Scope — เวอร์ชันแรก)
- ระบบชำระเงินออนไลน์ (ถ้ามีค่าใช้จ่ายค่าย อาจใช้แจ้งโอนและแนบสลิปแทนในช่วงแรก)
- เวอร์ชันภาษาอังกฤษ
- แอปมือถือแยกต่างหาก (ใช้เว็บ responsive ก่อน)
